# Rajkot Data Provenance

## What is real vs synthetic in the Rajkot dataset
Real OpenStreetMap data: road network (1,538 ways), hospitals and clinics, schools, fuel stations. Synthetic-but-geography-seeded: H3 population model (~9 lakh people, peak densities in the old city), land-use zones, Aji flood-risk bands, and the EV-competitor top-up. Swapping any synthetic layer for municipal data needs no code changes.
