# Catchment Analysis Method

## Catchment analysis method and limits
Catchment rings estimate population reachable within 10, 20 and 30 minutes using an urban travel speed of 18 km/h (3, 6, 9 km straight-line radii), intersected with the H3 population grid. This approximates road-network isochrones: real reachable areas follow streets and congestion, so treat values as planning estimates. An OSRM/Valhalla isochrone upgrade is documented and requires no API change.
