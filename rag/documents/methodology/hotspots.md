# Hotspot Grid Methodology (H3)

## Hotspot grid methodology
The readiness heatmap divides the study area into H3 resolution-8 hexagonal cells. Each cell's centroid is scored with the same five factors as a point site, then combined with the active business weights. Cells on protected or critical-risk land render as Restricted. Raw per-cell factors are precomputed so weight changes re-render instantly.
